# 上海地铁运行图 · 动态模拟

按一天中的不同时刻动态显示上海地铁各线路列车运行情况的 2D 线路图（纯前端单页实现，无构建步骤）。

## 功能

- 全部 20 条线路（含 4 号线内外环、5/10/11 号线支线交路、磁悬浮相邻线路之外的市域机场线等）
- 每条线路、每个方向独立显示列车：实心圆点 = 始发方向，空心圆点 = 对向；同线多车可直接观察发车间隔
- 时间轴拖动 + 播放/暂停 + 4 档倍速；清晨 → 早高峰 → 平峰 → 晚高峰 → 深夜的间隔变化一目了然
- 地图支持滚轮缩放、触屏双指缩放、拖拽平移、＋/－ 逐级缩放与一键重置视野
- 悬停线路/车站显示提示；点击线路（图上或右侧列表）查看该线双向首末班车时段、全程运行时分、当前间隔与全天间隔曲线

## 数据来源

- 首末班车与站序：上海地铁官网接口（service.shmetro.com，工作日时刻）
- 站线示意坐标与线路配色：百度地图地铁示意数据
- 发车间隔：公开报道整理的近似值，仅供参考，以车站现场公告为准

## 运行

纯静态页面，直接用浏览器打开 `index.html`，或部署到任意静态托管（GitHub Pages 已启用时访问仓库 Pages 地址）。
